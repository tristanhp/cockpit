# S8 — La saison

Goal: the football-season layer, revealed once a week, plus the insight charts. Depends on S5 (clôture) and S7 (revue). Product rules: [SPEC.md](../SPEC.md) (La saison). Nothing in this slice shows during the week except the insight page; the Sunday revue reveals.

## 1. Data
- `matches`: day, planned points, done points, blocks planned, blocks kept, rituals planned, rituals done, mandatory missed, `goalsFor`, `goalsAgainst`, `ratio`, `result` (`V` | `N` | `D`), `points` (3, 1, 0), `cup` (boolean), `cupTitle`.
- `season_table`: season id, points, wins, draws, losses, goals for and against (computed from matches; never edited).
- `awards`: season id, kind, subject, value.
- `ratings`: pillar id, week start, rating 0–99 (history for the player card).

## 2. Scoring (pure, `src/engine/season.ts`, heavily unit-tested)
- A day is a match against that day's plan. `ratio = weighted done / weighted planned`, weights are effort points for tasks, one point per kept block, one per ritual. If nothing was planned the day is not a match.
- `result`: ratio ≥ 0.80 win (3 points), 0.60–0.80 draw (1), below 0.60 loss (0). Thresholds live in settings, with these defaults.
- `goalsFor` = effort points done + blocks kept + rituals done; `goalsAgainst` = mandatory items missed (a mandatory item is defined in S3). Display only; the result comes from the ratio.
- **Crise**: two losses in a row. **Form**: last five results.
- **Cup matches**: a day with an evaluation or a major milestone counts double goals and is flagged.
- **Player card**: rating per pillar from the last four weeks (effort done, blocks kept, habits at target, goal progress), documented in code comments and unit-tested for bounds and monotonicity; overall rating is the mean weighted by pillar priority.
- Matches are computed when a clôture closes the day (S5) and re-derived by a nightly pass for days without a clôture (those count as a match with only what was done and a ritual miss).

## 3. Reveal and screens
- In the Sunday revue (S7), add a step before the numbers: the week's fixtures (seven rows with result and score), the form guide, the table against past seasons, the crise question when it applies, and the player card with changes. Skippable, never blocking.
- `/saison`: the season at a glance (table, form, cup ties coming up, player card) and the insight charts: velocity (points done per week against budget), blocks kept (%), habits heatmap against the 80 % line, goal progress lines, and (when data exists) sport sessions and sleep numbers. Hand-written SVG using the design tokens; no chart library. Every chart has a text summary for accessibility.
- Season end: an awards and recap card (best pillar, top-scoring project, longest run of wins, biggest comeback) generated when a season's end date passes, stored in `awards`.
- Settings: thresholds, whether the daily result is shown at the clôture (off by default).

## Done when
- In demo mode: a generated history of matches produces a believable table, form and crise; the revue reveal and `/saison` render with the demo data; unit tests cover thresholds, crise, cup doubling, the player card bounds and the table.
- `npm run check` passes.
